Tailscale Network & Cloud VPS Deployment

Obrigado is designed to run securely over your private Tailscale network. Your VPS can serve this web app directly to your phone, laptop, and iPad with zero public internet exposure or port forwarding!

// 1. Run Obrigado on your VPS:
python run.py
// 2. Expose securely to your Tailscale mesh with automatic HTTPS:
tailscale serve --bg 8000
// 3. Access from any device on your Tailscale network at:
https://<your-vps-hostname>.<your-tailnet>.ts.net
